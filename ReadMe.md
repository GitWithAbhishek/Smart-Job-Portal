# Smart Job Portal

**Smart Job Portal** is a full-stack MERN application where employers can post jobs and job seekers can search and apply. It features authentication, role-based dashboards, and a responsive interface. This repository contains the complete frontend (React) and backend (Node/Express with MongoDB) source code.

## Features
- User authentication (Login/Signup)
- Role-based dashboards
- Job posting, searching, and applying
- Responsive UI design

## Tech Stack
- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB

## Project Structure
```

smart-job-portal/
│── client/        # React frontend
│── server/        # Node/Express backend
│── README.md

````

## Getting Started
Clone the repository and install dependencies:

```bash
git clone https://github.com/your-username/smart-job-portal.git
cd server && npm install
cd ../client && npm install
````

Start servers:

```bash
# Backend
cd server && npm start

# Frontend
cd ../client && npm start
```
